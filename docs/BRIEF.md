# Trackfluence — One-Page Brief

> *May 2026 — For sharing with investors, partners, and design agencies*

---

## What It Is

**Trackfluence** is a B2B SaaS platform that gives brands **proof of ROI from creator marketing** — tracking which creator drove each sale, calculating fair commissions, and automating payouts.

---

## The Problem

Brands spend **$21B/year** on creator marketing with no reliable way to answer:
- *"Which creator actually drove that sale?"*
- *"What are those customers worth long-term?"*
- *"Am I paying my creators the right amount?"*

Current tools (GA4 UTMs, promo codes, spreadsheets) are fragmented, inaccurate, and manual.

---

## The Solution

Trackfluence closes the loop between **creator activity** (link clicks) and **revenue events** (purchases) through a multi-touch attribution engine.

```
Creator link click → Customer buys → Trackfluence matches them → Commission calculated → Payout approved
```

One platform for attribution, intelligence, compliance, and payouts.

---

## Key Features

- 🔗 **Tracking links** — short codes with UTM + QR code + promo code support
- 📊 **4 attribution models** — First Touch, Last Touch, Linear, Time Decay
- 🧠 **Creator scores (0–100)** — revenue-based performance tier (Platinum → Bronze)
- 💸 **Payout automation** — calculate → approve → CSV in minutes
- 🎯 **Audience segmentation** → export to Salesforce / Shopify
- ✅ **FTC compliance** — auto-detect missing disclosures, auto-email creators
- 🔔 **Real-time** — Socket.io + Slack + Discord alerts
- 🏢 **Multi-tenancy** — org roles, team invites
