## 9. How It Works Section

**Eyebrow:** How It Works

**Headline:**
> From First Click to Final Payout — In One Platform

**5-step visual flow:**

1. **Add your creators** — Import a CSV or add one by one. Set their commission rate. Send them a portal invite.

2. **Create a campaign** — Name it, set a budget, assign creators. Generate tracking links in seconds.

3. **Creators share links** — Instagram bio, TikTok description, YouTube cards. Every click is captured.

4. **Revenue flows in** — Shopify sends order webhooks. Trackfluence matches each order to a creator journey.

5. **Intelligence + payouts** — See ROI by creator. One-click approve payouts. Finance downloads the CSV. Done.
